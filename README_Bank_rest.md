# Система управления банковскими картами 🚀

Добро пожаловать в проект **Card Management System** — backend-приложение для управления банковскими картами, разработанное на **Java 17** и **Spring Boot**. Оно обеспечивает создание, управление и переводы между картами с ролевым доступом для администраторов и пользователей, с акцентом на безопасность, аутентификацию и авторизацию через **Spring Security** и **JWT**.

---

## 📋 Описание проекта

Приложение предоставляет функционал для управления банковскими картами, включая создание, просмотр, блокировку и переводы между картами. Оно поддерживает ролевой доступ (`ADMIN` и `USER`), шифрование данных и удобный API с документацией через Swagger.

---

## ✨ Возможности

### 👑 Администратор
- Создание, блокировка, активация и удаление карт.
- Управление пользователями: создание, изменение ролей, блокировка/активация.
- Просмотр всех карт в системе.

### 👤 Пользователь
- Просмотр своих карт с поддержкой поиска и пагинации.
- Запрос на блокировку карты.
- Перевод средств между своими картами.
- Проверка баланса.

### 💳 Атрибуты карты
- **Номер карты**: Зашифрован, отображается в формате `**** **** **** 1234`.
- **Владелец**: Логин пользователя.
- **Срок действия**: Формат `yyyy-MM`.
- **Статус**: `Активна`, `Заблокирована`, `Истек срок`.
- **Баланс**: Текущий доступный баланс.

## ⚙️ Установка и запуск

### 📋 Требования
- **Java 17+**
- **Docker** и **Docker Compose**
- **PostgreSQL** или **MySQL**
- **Maven**

### 🚀 Инструкция по запуску

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd bank_rest
   ```

2. **Настройка базы данных**
    - Убедитесь, что PostgreSQL или MySQL запущены.
    - Настройте `src/main/resources/application.yml`:
      ```yaml
      spring:
        datasource:
          url: jdbc:postgresql://localhost:5432/card_db
          username: your_username
          password: your_password
      ```

3. **Сборка проекта**
    - Скомпилируйте проект для создания артефакта в папке `target`:
      ```bash
      mvn clean package
      ```

4. **Запуск через Docker Compose**
    - Убедитесь, что в корне проекта есть файл `docker-compose.yml`.
    - Выполните сборку и запуск контейнеров:
      ```bash
      docker-compose build
      docker-compose up -d
      ```

5. **Локальный запуск (альтернатива)**
    - После сборки проекта запустите приложение:
      ```bash
      mvn spring-boot:run
      ```

6. **Доступ к приложению**
    - Приложение: `http://localhost:8080`
    - Swagger UI: `http://localhost:8080/swagger-ui.html`

## 📚 Документация API

- API задокументирован с использованием **Swagger (OpenAPI)**.
- Доступ к Swagger UI: `/swagger-ui.html`.
- Полная спецификация: `docs/openapi.yaml`.

### Основные эндпоинты
- `/api/auth/register`: Регистрация нового пользователя.
- `/api/auth/login`: Аутентификация и получение JWT-токена.
- `/api/card`: Управление картами (создание, просмотр, обновление, удаление).
- `/api/cardBlock`: Управление запросами блокировки карт (создание, просмотр, обновление, удаление).
- `/api/user`: Управление пользователями (только для администратора).
